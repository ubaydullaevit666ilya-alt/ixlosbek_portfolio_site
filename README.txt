IXLOSBEK — PYTHON PORTFOLIO
===========================

Локальный запуск на Ubuntu
--------------------------
1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Создайте виртуальное окружение:

   python3 -m venv .venv
   source .venv/bin/activate

4. Установите зависимости:

   pip install -r requirements.txt

5. Запустите сайт:

   python app.py

6. Откройте в браузере:

   http://127.0.0.1:5000

   Режим отладки (автоперезагрузка): FLASK_DEBUG=1 python app.py
   Другой порт: PORT=8000 python app.py

Как работает эффект «сайт программирует сам себя»
-------------------------------------------------
Python/Flask формирует страницу и передаёт список строк терминала.
JavaScript по очереди выводит строки и двигает индикатор загрузки.
Когда интро заканчивается, оно исчезает, а секции сайта плавно появляются.
Кнопка «Пропустить интро» позволяет сразу открыть портфолио.

Где менять данные
-----------------
- Имя, Telegram, email, проекты и навыки: app.py
- HTML-разметка: templates/index.html
- Оформление: static/style.css
- Эффекты загрузки и меню: static/app.js
- Строки интро-терминала: BOOT_LINES в app.py
- Фоновое видео: static/bg.mp4 (отключается при «уменьшении анимации»)

Примечание
----------
Это визуальная анимация. Сайт не переписывает и не компилирует собственный
исходный код в браузере: он показывает стилизованный процесс запуска.
Для публикации в интернете настройте Flask через WSGI на своём хостинге.
Не запускайте встроенный debug-сервер Flask как публичный production-сервер.
